# InterviewIQ - AI Powered Interview Preparation Platform 🚀

InterviewIQ is an AI-powered interview preparation platform designed to help
students and professionals prepare for technical and behavioral interviews.

The platform provides AI-based mock interviews, resume analysis, performance
evaluation, coding practice, and personalized feedback to improve interview
skills.

---

## ✨ Features

- 🔐 Secure User Authentication using JWT
- 📄 AI Resume Analysis
- 🤖 AI Mock Interview System
- 🎤 Voice-Based Interview Support
- 💻 Coding Interview Practice
- 📊 Performance Analytics Dashboard
- 📝 AI Generated Interview Reports
- 📥 Download Interview Reports as PDF
- 🛣️ Personalized Learning Roadmap
- 📈 Interview Performance Tracking
